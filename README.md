# G-Power Manufacturing PLC

Premium one-page website for G-Power — renewable energy, solar, and energy storage solutions in Ethiopia.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lenis
- Embla Carousel
- React Hook Form + Zod
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Images

Place your production assets in `public/images/`:

- `hero.jpg`, `about.jpg`
- `service1.jpg`–`service3.jpg`
- `project1.jpg`–`project4.jpg`
- `team1.jpg`–`team4.jpg`
- `client1.png`–`client4.png`
- `battery.jpg`, `solar.jpg`, `warehouse.jpg`

Temporary branded placeholders are included so the site runs out of the box. Replace them with your real photography.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint
